# API Classificador de Texto

API back-end para classificação de textos, com foco na detecção
de conteúdo ofensivo e spam.

## Objetivo
Projeto desenvolvido para estudo de lógica, regras de negócio
e processamento básico de texto.

## Tecnologias previstas
- Java
- Spring Boot
- REST API
